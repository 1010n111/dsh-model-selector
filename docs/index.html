模型选择器插件

之前自用的一个插件，把模型搜索、供应商分组和推理强度调整放在同一个菜单里。

$dsh plugin --profile web add @bittersmilezzz/dsh-model-selector

需要先安装 DSH。适配 DSH ^0.2.1-rc.2、Node.js ≥22.19.0；上方命令安装到 web profile，启用后刷新页面。

交互示意 · 使用示例数据，不连接模型
推理等级
Medium

可选档位取决于模型。示例模型提供 5 档。

功能与使用说明

模型分组

在同一个菜单中查看模型，按供应商展开或折叠。

推理强度

通过滑杆调整模型提供的推理档位。实际可选档位以模型目录为准。

模型搜索

按名称或供应商筛选；插件支持键盘选择与中文输入法。

权限

纯客户端 UI，不读写宿主文件或访问凭据；模型切换使用 DSH 的会话接口。

兼容性

使用 DSH 的模型选择插槽。与其他接管同一位置的插件可能冲突，宿主接口变更时需适配。

反馈

遇到问题可以到 GitHub Issues 反馈，并附上 DSH 和插件版本。
